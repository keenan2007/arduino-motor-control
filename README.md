# arduino-mechanical-claw
Arduino Controlled Mechanical Claw System mounted to a rail system capable of automated gripping.

## Overview
This project was a team-based engineering design project involving the development of an Arduino-controlled mechanical claw mounted on a rail system.

The system was designed to detect objects and automatically open and close the claw using sensors, servo motors, and Arduino control logic.
## How It Works
The system uses sensors to detect objects near the claw. The Arduino processes the sensor input and controls servo motors that open and close the claw.

The claw is mounted on a rail system, allowing the mechanism to interact with objects while combining mechanical components with electronic control.

## Components
- Arduino microcontroller
- Servo motors
- Sensors
- Mechanical metal claw
- Rail system
- Structural and mounting components

## Programming
The control logic was programmed in C using Arduino.

The program handled:
- Sensor input
- Object detection
- Servo actuation
- Opening and closing of the claw

## Design Challenges
One of the main challenges was getting the claw to grip objects reliably.

The original mechanical design did not create enough grip, causing objects to slip. The claw was tested and modified to improve contact with the object, including changes to the gripping surfaces.

This process involved repeated prototyping, testing, and troubleshooting.
